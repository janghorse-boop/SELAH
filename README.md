# SELAH RTA

**Real-Time Worship Audio Analyzer** — 교회 예배당용 실시간 주파수 분석기

폰 브라우저로 열어 예배당 소리를 31밴드로 보고, **하울링이 시작되면 「어느 EQ 슬라이더를
몇 dB 내릴지」** 알려줍니다.

## 왜 만드나

막대 그래프를 그려주는 RTA 앱은 이미 많습니다. 그런데 어느 것도
**「당신 콘솔의 3.15k 슬라이더를 6dB 내리세요」** 라고 말해주지 않습니다.
전부 숫자를 읽을 줄 아는 사람을 전제합니다.

SELAH RTA 는 **읽는 앱이 아니라 조치하는 앱**입니다.
가지고 계신 그래픽 EQ 의 밴드 수(31·15·10)에 맞춰, **실제로 손에 있는 슬라이더
이름으로** 알려줍니다.

## 무엇을 하나

- **31밴드 실시간 RTA** — ISO 표준 중심 주파수. 콘솔 슬라이더와 이름이 일치합니다
- **하울링 탐지 + 컷 권고** — 공개 학술 기준 5가지를 모두 만족할 때만 경고합니다.
  소프라노 고음과 하울링을 가려냅니다
- **리허설 모드 / 예배 모드** — 예배 중에는 검은 화면, 진동 알림, 알림음 없음
- **소스별 음향 가이드 7종** — 설교자 · 보컬 · 신디 · 어쿠스틱기타 · 베이스 · 일렉기타 ·
  전자드럼. 각 항목에서 해당 대역을 RTA 로 바로 확인할 수 있습니다

## 무엇을 하지 않나

- **자동 EQ · 자동 컷을 하지 않습니다.** 이 앱은 소리 경로에 끼어들지 않습니다 —
  듣고 알려줄 뿐, 필터를 넣거나 게인을 만지지 않습니다
- 서버 · 로그인 · 계정이 없습니다
- 녹음하지 않습니다. 측정 결과도 **어디에도 남기지 않습니다** — 화면을 나가면
  그대로 사라집니다. 폰에 저장되는 것은 설정값뿐입니다

## 주의

**폰 마이크는 측정용 장비가 아닙니다.** 절대 음압(dB SPL)은 근사치이며, 기본값은
상대 레벨만 보여줍니다. **소음 규제·안전 판단에 쓰지 마십시오.**

가이드의 주파수 숫자는 **출발점이지 정답이 아닙니다.** 예배당마다 다릅니다 —
짐작한 뒤 RTA 로 확인하고 조정하십시오.

## 기술

React + Vite + TypeScript + Tailwind · 브라우저 내장 Web Audio API ·
외부 오디오 라이브러리 없음 · GitHub Pages 배포

판단 로직(밴드 묶기 · 하울링 판정 · 컷 권고)은 **브라우저와 무관한 순수 함수**로
분리되어 있어, 합성 신호를 넣어 실제로 검증할 수 있습니다.
